# القرآن والأذكار — Quran & Adhkar

تطبيق هاتف (أندرويد وآيفون) مبني بـ **React Native + Expo**، يجمع:

- 🕌 **مواقيت الصلاة** (الميزة الأساسية): حساب دقيق على الجهاز بدون إنترنت، الصلاة القادمة مع عدّ تنازلي وشريط تقدّم، التاريخ الهجري، اختيار تلقائي لطريقة الحساب حسب الدولة، ومذهب العصر.
- 🔔 **تنبيهات الأذان**: تفعيل/إيقاف لكل صلاة، وتُجدول تلقائياً للأيام السبعة القادمة.
- 📖 **القرآن الكريم كاملاً** بالرسم العثماني (114 سورة، 6236 آية) بدون إنترنت، عرض متصل مثل المصحف، فهرس السور والأجزاء، بحث، وحفظ موضع القراءة.
- 🤲 **الأدعية والأذكار** من حصن المسلم: الصباح، المساء، بعد الصلاة، النوم، الاستيقاظ، الأذان والمسجد، المنزل، الطعام، السفر، أدعية قرآنية ونبوية — مع المصدر وعدّاد التكرار.
- 🧭 **اتجاه القبلة** ببوصلة حيّة والمسافة إلى مكة.
- 🌗 وضع ليلي، 🔠 تخصيص حجم الخط، 🌐 واجهة عربية وإنجليزية (RTL/LTR).

## التشغيل

```bash
npm install
npx expo start
```

ثم امسح رمز QR بتطبيق **Expo Go** على هاتفك (أندرويد أو آيفون).

> ملاحظة: البوصلة والإشعارات تعمل على الهاتف الحقيقي فقط. لتجربة كاملة لتنبيهات الأذان يُفضّل بناء نسخة تطوير:
> `npx eas-cli@latest build --profile development --platform android`

## البناء والنشر (بدون جهاز ماك)

```bash
npx eas-cli@latest login
npx eas-cli@latest build --platform android --profile preview   # ملف APK للتجربة
npx eas-cli@latest build --platform android --profile production
npx eas-cli@latest build --platform ios --profile production    # يتطلب حساب Apple Developer
```

## هيكل المشروع

```
src/
  app/            الشاشات (Expo Router): (tabs)/ الصلاة، القرآن، الأذكار، القبلة، الإعدادات + surah/[id] + duas/[category]
  components/     مكونات الواجهة (بطاقة الصلاة القادمة، البوصلة، بطاقة الذكر...)
  context/        الإعدادات المحفوظة (AsyncStorage)
  data/           القرآن (quran.ts) والأذكار (duas.ts)
  i18n/           النصوص العربية والإنجليزية
  lib/            حساب المواقيت، القبلة، التاريخ الهجري، الإشعارات، الموقع
  theme.ts        الألوان والخطوط (فاتح/داكن)
assets/data/quran.json   نص القرآن الكريم
scripts/prepare-quran.mjs  تجهيز ملف القرآن من المصدر
```

## المصادر والرخص

- **نص القرآن**: الرسم العثماني من [موسوعة القرآن الكريم](https://quranenc.com) عبر حزمة [`quran-json`](https://github.com/risan/quran-json) (رخصة CC BY 4.0). عُدّلت رموز التنوين المفتوح إلى ترميز Unicode القياسي ليعرضها الخط بشكل صحيح (`scripts/prepare-quran.mjs`).
- **حساب المواقيت والقبلة**: مكتبة [`adhan`](https://github.com/batoulapps/adhan-js) (MIT).
- **الخطوط**: Amiri Quran و IBM Plex Sans Arabic (رخصة SIL OFL).
- **الأذكار**: كتاب حصن المسلم، مع ذكر مصدر كل ذكر.
